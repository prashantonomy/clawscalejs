# Security policy

## Supported versions

Security fixes land in the latest minor release of `@clawscale/react` and `@clawscale/tokens`.

## Reporting a vulnerability

Report privately through this repository's Security tab: **Report a vulnerability**. Do not open a public issue.

Include the affected package and version, steps to reproduce and the impact you expect.

We aim to acknowledge reports within 3 business days and to ship a fix or a plan within 14 days.

## Scope

- `@clawscale/react` and `@clawscale/tokens`
- The documentation site and its build

Issues in Blueprint itself also belong upstream: https://github.com/palantir/blueprint/security
