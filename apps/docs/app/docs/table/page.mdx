# Table

`@clawscale/react/table` renders interactive, spreadsheet-like tables for large datasets. For a static table, use [HTML table](/docs/core/html-table/).

## Usage

```tsx
import { Cell, Column, Table } from "@clawscale/react/table";
```

The styles ship in `@clawscale/react/styles.css`. There is no extra stylesheet to load.

## Examples

### Basic

The table stores no data. Set `numRows`, then give each `Column` a `cellRenderer` that returns a `Cell` for a row index. `intent` colors a cell.

## Tabular numbers

Clawscale turns on tabular numbers in every table, so each digit takes the same width. Right-align numeric cells, like Rows and Duration above, and digits line up by place value.

## Sizing

The table fills the height of its container and measures it after mount. Give the container a height, either fixed or from a flex or grid layout. Only the cells in view render, so large row counts stay fast.
