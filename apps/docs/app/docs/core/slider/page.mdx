# Slider

A **Slider** picks a number from a range. A **RangeSlider** picks a start and an end, and a **MultiSlider** takes any number of handles.

## Usage

```tsx
import { MultiSlider, MultiSliderHandle, RangeSlider, Slider } from "@clawscale/react";
```

```tsx
<Slider max={32} value={workers} onChange={setWorkers} />
```

Sliders are controlled. Pass `value` and update it in `onChange`. `onRelease` fires once when the user lets go of a handle.

## Examples

### Single value

`min`, `max` and `stepSize` define the scale, and `labelStepSize` spaces the labels. Name the handle with `handleHtmlProps`.

### Range

**RangeSlider** takes a `[start, end]` pair and fills the track between the two handles.

### Multiple handles

**MultiSlider** renders one **MultiSliderHandle** per value. `intentBefore` and `intentAfter` color the track on each side of a handle, which suits threshold bands.

<Example name="core/slider/multi" align="start">

</Example>

### Vertical

`vertical` draws the track from bottom to top.

### Label renderer

`labelRenderer` formats labels, for example as a percentage or in milliseconds. Its second argument tells you when the label is the handle's own tooltip.
