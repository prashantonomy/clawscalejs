# HTML table

**HTMLTable** styles a native `table` element. Use it for small, static tables. For large or editable data, use the [Table](/docs/table/) package.

## Usage

```tsx
import { HTMLTable } from "@clawscale/react";
```

```tsx
<HTMLTable compact striped>
  <thead>{/* header row */}</thead>
  <tbody>{/* data rows */}</tbody>
</HTMLTable>
```

## Examples

### Basic

Render `thead` and `tbody` as children. Right-align number columns and add the `cs-numeric` class: it switches to tabular figures, so digits line up.

### Striped

`striped` shades every other row, which helps the eye follow long rows.
