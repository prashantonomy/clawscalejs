# Segmented control

A **SegmentedControl** picks one value from a few options shown as joined buttons. Use it for time ranges, view switches and short filters.

## Usage

```tsx
import { SegmentedControl } from "@clawscale/react";
```

```tsx
<SegmentedControl options={[{ label: "24h", value: "24h" }, { label: "7d", value: "7d" }]} value={range} onValueChange={setRange} />
```

Each option takes a `label` and a `value`, plus an optional `icon` and `disabled`.
