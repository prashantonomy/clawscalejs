# Alert

An **Alert** makes the user confirm or acknowledge something before they continue. Use it for destructive actions and critical notices. For everything else, use a [Dialog](/docs/core/dialog/).

## Usage

```tsx
import { Alert } from "@clawscale/react";
```

Alert is controlled with `isOpen`. Handle `onConfirm` and `onCancel` separately, or both in `onClose`, which receives `true` when the user confirmed.

By default, only the buttons close an alert. Escape and clicks outside do nothing.

## Examples
