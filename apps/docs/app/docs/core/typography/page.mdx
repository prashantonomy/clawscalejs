# Typography

Clawscale sets text in Inter and code in JetBrains Mono, on a 13px base size for dense screens.

## Usage

```tsx
import { Code, H1, H2, H3, H4, H5, H6, Pre, Text } from "@clawscale/react";
```

## Fonts

`@clawscale/react/fonts.css` loads Inter and JetBrains Mono as variable fonts. Import it once, next to `styles.css`.

```tsx
import "@clawscale/react/fonts.css";
```

Without it, text falls back to the system fonts in each stack. To use your own fonts, set `--cs-font-sans` and `--cs-font-mono`.

## Type scale

Eight sizes, from `xs` to `4xl`. Body text uses `md`.

<TokenTable group="font-size" />

Use the tokens in your own CSS. Weights and line heights are tokens too, listed in [Tokens](/docs/core/tokens/).

```css
.panel-title {
  font-size: var(--cs-font-size-lg);
  font-weight: var(--cs-font-weight-semibold);
  line-height: var(--cs-line-height-tight);
}
```

Wrap long-form HTML in `Classes.RUNNING_TEXT`. It styles nested paragraphs, lists, code and block quotes, so plain markup needs no components.

## Tabular numbers

Inter draws digits with different widths by default. Add the `cs-numeric` class (`ClawscaleClasses.NUMERIC`) to give every digit the same width, so numbers line up in columns. The Table component, date pickers and slider labels already use tabular numbers.

</Example>

## Code

`Code` renders inline code. `Pre` renders a preformatted block. Both use `--cs-font-mono`.

## Text

`Text` with `ellipsize` cuts overflowing text to one line and ends it with an ellipsis. When the text overflows, it also sets `title` to the full text. [Text](/docs/core/text/) lists its props.
