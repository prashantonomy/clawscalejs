# Skeleton

A skeleton is a placeholder shown while data loads. It is a CSS class, not a component: add `Classes.SKELETON` to any element.

## Usage

```tsx
import { Classes } from "@clawscale/react";
```

```tsx
<H5 className={loading ? Classes.SKELETON : undefined}>orders_daily</H5>
```

In a React Server Component, import `Classes` from `@clawscale/react/common`.

The element keeps its size, so the layout does not shift when the data arrives. Its content is hidden, it glows, and it ignores the pointer. The glow stops for users who prefer reduced motion.
