# Tree

A **Tree** shows hierarchical data, such as folders of datasets. It holds no state: you pass the nodes and handle expansion and selection.

## Usage

```tsx
import { Tree, type TreeNodeInfo } from "@clawscale/react";
```

Each node needs a unique `id` and a `label`. `childNodes` makes it expandable. More than one top-level node makes a tree with several roots.

## Examples

### Dataset browser

Keep the expanded ids and the selected id in state, and set `isExpanded` and `isSelected` from them. `icon` and `secondaryLabel` add context to each row.
