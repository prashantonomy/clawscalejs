# Tag input

A **TagInput** collects a list of short values, such as regions, owners or table names, and shows each one as a [Tag](/docs/core/tag/).

## Usage

```tsx
import { TagInput } from "@clawscale/react";
```

```tsx
<TagInput values={regions} onChange={(values) => setRegions(values.map(String))} />
```

**TagInput** is always controlled: pass `values` and update them in `onChange`, or in `onAdd` and `onRemove`. Enter adds the typed text. Backspace at the start of the field selects the last tag, and a second Backspace removes it.

`tagProps` styles the tags. Pass an object for every tag, or a function to style each value on its own.

### Separators

`separator` splits typed or pasted text into several tags. The default splits on commas and new lines. Set it to `false` to keep text whole.
