# Drawer

A **Drawer** slides in from an edge of the screen, above the page. Use it for inspectors and detail panels that keep the page in view.

## Usage

```tsx
import { Classes, Drawer, DrawerSize } from "@clawscale/react";
```

Drawer is controlled with `isOpen` and calls `onClose` like a [Dialog](/docs/core/dialog/). Put the content in a `Classes.DRAWER_BODY` element so it scrolls, and actions in `Classes.DRAWER_FOOTER`.

### Size

`size` sets the width of a left or right drawer and the height of a top or bottom one. It takes any CSS length. `DrawerSize` has three presets: `SMALL` (360px), `STANDARD` (50%, the default) and `LARGE` (90%).

</Example>
