# Tokens

Tokens are CSS variables named `--cs-*`. Clawscale's styles read them, so one override restyles every component that uses the token.

## Usage

### CSS

`@clawscale/react/styles.css` declares every token of the default theme, for both color schemes. Theme stylesheets such as `@clawscale/react/themes/futuristic.css` set their own values. Read them with `var()`.

```css
.queue-panel {
  background: var(--cs-color-surface);
  border: 1px solid var(--cs-color-border);
  border-radius: var(--cs-radius-lg);
  padding: var(--cs-space-4);
}
```

Elements styled with tokens follow the theme and the color scheme. Press Shift + T or Shift + D to switch them and watch this panel.

### JavaScript

Install `@clawscale/tokens` to read the values in code, for example for a canvas chart.

```bash
npm install @clawscale/tokens
```

```tsx
import { dark, light, shared, themes } from "@clawscale/tokens";

light.color.surface; // "#FFFFFF"
dark.color.surface; // "#16171B"
shared.radius.md; // "6px"
themes.futuristic.dark.color.surface; // "#07121A"
```

`light`, `dark` and `shared` are the default theme. `themes` holds every theme, each with `shared`, `light`, `dark` and `sequential`. `light` and `dark` hold `color`, `shadow` and `chart`. `shared` holds the groups that do not change with the color scheme. `chartPalettes` and `sequentialBlue` hold chart colors. `themeVariables(theme, colorScheme)` and `sharedVariables(theme)` return the values keyed by variable name, such as `"--cs-radius-md"`.

### Without Clawscale styles

`@clawscale/tokens/tokens.css` declares the default theme's variables alone, outside any cascade layer. The dark values apply under `[data-cs-color-scheme="dark"]`. `@clawscale/tokens/themes/futuristic.css` adds the futuristic theme under `[data-cs-theme="futuristic"]`. Use them on pages that do not load `@clawscale/react/styles.css`. `@clawscale/tokens/tokens.json` holds the same values for other tools.

```css
@import "@clawscale/tokens/tokens.css";
@import "@clawscale/tokens/themes/futuristic.css";
```

## Override a token

Set the variable in your own CSS. Unlayered CSS beats both Clawscale layers, so you never need `!important`.

```css
:root {
  --cs-radius-md: 4px;
  --cs-color-primary-text-light: #0b6b5c;
  --cs-color-primary-text-dark: #4fd1b8;
}
```

Color, shadow and chart tokens have a light and a dark value, such as `--cs-color-primary-text-light` and `--cs-color-primary-text-dark`. Set both, and each color scheme picks its own. [Theming](/docs/theming/) covers brand colors and scoped overrides.
