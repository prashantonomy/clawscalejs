# Tooltip

A **Tooltip** shows a short hint while the pointer is over its target or the target has focus. It is a hover-only [PopoverNext](/docs/core/popover/).

## Usage

```tsx
import { Tooltip } from "@clawscale/react";
```

Pass the target as the only child and the hint as `content`. Keep it to a few words. Put interactive content in a popover instead.

### Disabled buttons

Some browsers send no mouse events to a disabled `<button>`, so its tooltip never opens. Use `AnchorButton`, which stays hoverable when disabled. Or wrap the button in a `span` and turn off the button's pointer events.

## With a popover

A target can have both a tooltip and a popover. Put the Tooltip inside the PopoverNext. The tooltip then hides while the popover is open. Set `openOnTargetFocus={false}` so it does not reopen when focus returns to the target.

```tsx
<PopoverNext content={exportMenu} placement="bottom-start">
  <Tooltip content="Export" openOnTargetFocus={false}>
    <Button aria-label="Export" icon="export" />
  </Tooltip>
</PopoverNext>
```
