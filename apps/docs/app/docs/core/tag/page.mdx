# Tag

A **Tag** labels an item with a short piece of text, such as a status, a category or a filter. For key and value pairs, use a [Compound tag](/docs/core/compound-tag/).

## Usage

```tsx
import { Tag } from "@clawscale/react";
```

```tsx
<Tag intent="success" minimal>
  Healthy
</Tag>
```

### Minimal

`minimal` uses a light tint instead of a solid fill. Use it in dense tables and lists.

</Example>

### Interactive

`interactive` adds hover styles and keyboard support. A tag with `onClick` is interactive by default. `active` marks it as selected and applies only to interactive tags.

<Example name="core/tag/interactive">
  <TagInteractive />
</Example>

### Removable

`onRemove` adds a remove button at the end of the tag.

### Round

`round` gives the tag fully rounded ends.

  <TagRound />

`icon` renders before the text and `endIcon` after it.
