# Callout

A **Callout** highlights information the reader should not miss. It holds an optional title, an icon and any content.

## Usage

```tsx
import { Callout } from "@clawscale/react";
```

```tsx
<Callout intent="warning" title="Quota at 85%">
  The warehouse throttles queries above 100%.
</Callout>
```

`intent` sets the color and a matching icon. Set `icon` to replace the icon, or `icon={null}` to remove it.

`compact` reduces the padding. Use it in dense panels and forms.

### Minimal

`minimal` removes the background fill, for notes that should not compete with the content around them.
