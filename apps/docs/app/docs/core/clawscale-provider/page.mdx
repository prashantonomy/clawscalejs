# Clawscale provider

**ClawscaleProvider** is the root provider of a Clawscale app. It renders Blueprint's [BlueprintProvider](/docs/core/blueprint-provider/) for overlays, hotkeys and portals, and manages the theme and the light, dark and system color schemes. Wrap your app in it once.

## Usage

```tsx
import { ClawscaleProvider, ThemeScript } from "@clawscale/react";
```

In Next.js, render the provider in a client component and the theme script in `<head>`.

```tsx
// app/providers.tsx
"use client";

import { ClawscaleProvider } from "@clawscale/react";

export function Providers({ children }: { children: React.ReactNode }) {
  return <ClawscaleProvider>{children}</ClawscaleProvider>;
}
```

```tsx
// app/layout.tsx
import { ThemeScript } from "@clawscale/react";
import { Providers } from "./providers";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <head>
        <ThemeScript />
      </head>
      <body>
        <Providers>{children}</Providers>
      </body>
    </html>
  );
}
```

See [Next.js](/docs/nextjs/) for the full setup.

## What it includes

- [OverlaysProvider](/docs/core/overlays-provider/): the stack of open dialogs, drawers and popovers.
- [HotkeysProvider](/docs/core/hotkeys-provider/): the hotkeys registered with useHotkeys, and the hotkeys dialog.
- [PortalProvider](/docs/core/portal-provider/): where portals render.
- The theme context that [useTheme](/docs/core/use-theme/) reads.

## Themes

The provider applies a [theme](/docs/themes/): `default` unless you pass `defaultTheme`, or a theme someone picked with `setTheme`. A theme other than the default needs its stylesheet, such as `@clawscale/react/themes/futuristic.css`.

## Color schemes

The provider supports three color scheme preferences: `light`, `dark` and `system`. `system` follows the operating system through `prefers-color-scheme` and updates when it changes.

## Saved choices

- The theme is saved in `localStorage` under `clawscale-theme`, the color scheme under `clawscale-color-scheme`. Change the keys with `themeStorageKey` and `colorSchemeStorageKey`, or pass `null` to save nothing.
- `defaultTheme` and `defaultColorScheme` apply until someone picks one. They default to `default` and `system`.
- Both go on `<html>`: the theme as `data-cs-theme`, the color scheme as the `bp6-dark` class, `data-cs-color-scheme` and `color-scheme`. Portals follow them. Set `applyToDocument={false}` to skip this.
- Open tabs stay in sync. A change in one tab applies to the others.

## Theme script

The provider reads the saved theme and color scheme after hydration. On its own, the page would first paint with the defaults, then switch. **ThemeScript** prevents this flash: it runs before the first paint and applies both to `<html>`.

- Render it in `<head>`.
- Give it the same storage keys and defaults as the provider.
- Add `suppressHydrationWarning` to `<html>`, because the script changes its attributes before React hydrates.
- Pass `nonce` if your Content Security Policy requires one.

Outside React, `getThemeScript(options)` returns the script as a string.

## Controlled theme

Pass `theme` and `onThemeChange`, or `colorScheme` and `onColorSchemeChange`, to own a setting, for example to sync it with account settings. The provider still saves it to `localStorage`, so ThemeScript applies it on the next visit.

```tsx
<ClawscaleProvider colorScheme={colorScheme} onColorSchemeChange={saveColorScheme}>
  {children}
</ClawscaleProvider>
```

## Upgrading from 0.1

Before 0.2, "theme" meant light or dark. It now names the look, such as `futuristic`, and light and dark are color schemes.

| Before 0.2 | Now |
| --- | --- |
| `theme`, `defaultTheme`, `onThemeChange` with light, dark or system | `colorScheme`, `defaultColorScheme`, `onColorSchemeChange` |
| `resolvedTheme` | `resolvedColorScheme` |
| `setTheme("dark")` | `setColorScheme("dark")` |
| `storageKey` | `colorSchemeStorageKey` |
| `data-cs-theme="dark"` | `data-cs-color-scheme="dark"` |

The old names keep working until 1.0 and log a warning. A color scheme saved under `clawscale-theme` moves to `clawscale-color-scheme` on the next visit. Update CSS that selects `[data-cs-theme="dark"]` on `<html>`: the provider now writes the theme name there.
