# Context menu

A **ContextMenu** opens a menu of actions where the user right-clicks. It wraps a target element and shows a [PopoverNext](/docs/core/popover/) at the pointer.

## Usage

```tsx
import { ContextMenu, Menu, MenuItem } from "@clawscale/react";
```

ContextMenu renders a `div` around its children and passes extra props to it. Change the element with `tagName`.

### Imperative API

`showContextMenu` opens a menu at any position, for example from a canvas or chart event handler. `hideContextMenu` closes it. The menu renders in a separate React root, so it cannot read your React context.

## Without a wrapper

To skip the wrapper element, pass a function as `children`. Spread its class name, handler and ref onto your element and render its `popover`.

```tsx
<ContextMenu content={menu}>
  {(target) => (
    <div className={target.className} onContextMenu={target.onContextMenu} ref={target.ref}>
      {target.popover}
      orders_daily
    </div>
  )}
</ContextMenu>
```

`content` can also be a function. It receives `isOpen`, `targetOffset` and `mouseEvent`, for menus that depend on where the user clicked.

## Theme

Menus follow the dark color scheme through the `bp6-dark` class that [ClawscaleProvider](/docs/core/clawscale-provider/) puts on `<html>`.
