# Radio

A **Radio** picks one option from a set. A **RadioGroup** links its radios by `name` and marks the selected one.

## Usage

```tsx
import { Radio, RadioGroup } from "@clawscale/react";
```

```tsx
<RadioGroup name="codec" onChange={(event) => setCodec(event.currentTarget.value)} selectedValue={codec}>
  <Radio label="zstd" value="zstd" />
  <Radio label="gzip" value="gzip" />
</RadioGroup>
```

**RadioGroup** is always controlled, so `onChange` is required. Always pass a `name`. Without one, the group generates a name that differs between the server and the client render.
