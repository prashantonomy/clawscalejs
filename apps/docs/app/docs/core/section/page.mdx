# Section

A **Section** groups related content under a header. It looks like a [Card](/docs/core/card/) with a title, can collapse, and holds one or more **SectionCard** elements.

## Usage

```tsx
import { Section, SectionCard } from "@clawscale/react";
```

```tsx
<Section title="Schema" subtitle="24 columns">
  <SectionCard>{/* content */}</SectionCard>
</Section>
```

## Examples

### Basic

The header renders only when `title` is set. `subtitle` and `icon` are optional.

<Example name="core/section/basic" align="start">

### Collapsible

`collapsible` makes the header toggle the content. `collapseProps={{ defaultIsOpen: false }}` starts the section closed.

<Example name="core/section/collapsible" align="start">
  <SectionCollapsible />
</Example>

### Header actions

`rightElement` renders at the end of the header. Keep it to a small button or a tag.

<Example name="core/section/right-element" align="start">
  <SectionRightElement />
</Example>

### Compact

`compact` reduces the padding of the header and the cards.

  <SectionCompact />
</Example>

### Section cards

Cards stack inside a section, divided by borders. `padded={false}` removes the padding, for tables and lists that run edge to edge.
