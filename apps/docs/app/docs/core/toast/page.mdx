# Toast

A **Toast** is a short message about the result of an action. Toasts stack at an edge of the window and close on their own. An **OverlayToaster** shows them.

## Usage

Create one toaster for the whole app with `OverlayToaster.create`. It returns a promise that resolves to a `Toaster`.

```tsx
// toaster.tsx
import { OverlaysProvider, OverlayToaster, type Toaster } from "@clawscale/react";
import { createRoot } from "react-dom/client";

let toaster: Promise<Toaster> | undefined;

export function getToaster() {
  toaster ??= OverlayToaster.create(
    { position: "top" },
    {
      domRenderer: (element, container) =>
        createRoot(container).render(<OverlaysProvider>{element}</OverlaysProvider>),
    },
  );
  return toaster;
}
```

```tsx
const toaster = await getToaster();
toaster.show({ intent: "success", message: "Saved the view." });
```

- Call `getToaster` from event handlers, not during render. `OverlayToaster.create` needs `document`, so it cannot run on the server.
- The toaster renders in its own React root, outside ClawscaleProvider. `domRenderer` wraps it in an [OverlaysProvider](/docs/core/overlays-provider/). Without one, Blueprint logs an error in development.
- Each `create` call adds an element to the page. Create one toaster and share it.

The examples below import `getToaster` from a file like this one.

## Toaster methods

| Method | Description |
| --- | --- |
| `show(props, key?)` | Shows a toast, or updates the toast with that key. Returns the key. |
| `dismiss(key)` | Closes one toast. |
| `clear()` | Closes every toast. |
| `getToasts()` | Returns the open toasts as `ToastOptions`. |

`position` places the toaster at the `top` (default), `top-left`, `top-right`, `bottom`, `bottom-left` or `bottom-right` of the window. Use one toaster per position.
