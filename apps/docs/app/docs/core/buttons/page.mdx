# Buttons

A **Button** triggers an action. An **AnchorButton** looks the same and navigates.

## Usage

```tsx
import { AnchorButton, Button } from "@clawscale/react";
```

```tsx
<Button intent="primary" text="Save" />
```

## Examples

### Basic

Set the label with `text` or pass children.

<Example name="core/buttons/basic">
  <ButtonsBasic />
</Example>

### Intent

`intent` signals what the action does. Use **primary** for the main action on a screen and **danger** for destructive ones.

<Example name="core/buttons/intent">
  <ButtonsIntent />
</Example>

### Variant

`variant` sets the visual weight: **solid** (default), **outlined** or **minimal**. Use minimal buttons in toolbars and dense tables.

<Example name="core/buttons/variant">
  <ButtonsVariant />
</Example>

### Size

`size` accepts **small**, **medium** (default) and **large**.

<Example name="core/buttons/size">
  <ButtonsSize />
</Example>

### Icons

`icon` renders before the text and `endIcon` after it. Icon-only buttons need an `aria-label`.

<Example name="core/buttons/icons">
  <ButtonsIcons />
</Example>

### States

`active`, `disabled` and `loading` change how a button responds. A loading button keeps its width.

<Example name="core/buttons/states">
  <ButtonsStates />
</Example>

### Fill

`fill` stretches a button to its container. Pair it with `alignText` for menu-like triggers.

<Example name="core/buttons/fill">
  <ButtonsFill />
</Example>

## AnchorButton

**AnchorButton** renders an `<a>` element with button styles. Use it for navigation, not actions.
