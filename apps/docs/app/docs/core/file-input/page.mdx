# File input

A **FileInput** styles a native file picker. It renders a `<label>` around an `<input type="file">`.

## Usage

```tsx
import { FileInput } from "@clawscale/react";
```

```tsx
<FileInput text="Choose a CSV export" onInputChange={(event) => setFile(event.currentTarget.files?.[0])} />
```

**FileInput** does not show the chosen file by itself. Read it in `onInputChange`, then pass its name as `text` and set `hasSelection`.

`fill` stretches the field to the width of its container.
