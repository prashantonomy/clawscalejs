# Compound tag

A **CompoundTag** is a [Tag](/docs/core/tag/) split in two: a key on the left and a value on the right. Use it for properties and filters, such as `env` and `production`.

## Usage

```tsx
import { CompoundTag } from "@clawscale/react";
```

```tsx
<CompoundTag leftContent="env">production</CompoundTag>
```

## Examples

`leftContent` is the key. `children` are the value.
