# useTheme

**useTheme** reads and changes the theme and the color scheme that [ClawscaleProvider](/docs/core/clawscale-provider/) manages.

## Usage

```tsx
import { useTheme } from "@clawscale/react";
```

```tsx
const { theme, setTheme, colorScheme, resolvedColorScheme, setColorScheme } = useTheme();
```

Outside a ClawscaleProvider, it returns the default theme in light and setters that do nothing.

## Return value

| Property | Type | Description |
| --- | --- | --- |
| `theme` | `ThemeName` | The theme: `"default"`, `"futuristic"` or your own. |
| `setTheme` | `(theme: ThemeName) => void` | Changes the theme and saves it. |
| `colorScheme` | `ColorSchemePreference` | The saved preference: `"light"`, `"dark"` or `"system"`. |
| `resolvedColorScheme` | `ColorScheme` | The color scheme applied now: `"light"` or `"dark"`. |
| `setColorScheme` | `(colorScheme: ColorSchemePreference) => void` | Changes the preference and saves it. |

`@clawscale/react` exports these types, and `ThemeContextValue` for the whole object. `resolvedTheme` remains as a deprecated name for `resolvedColorScheme` until 1.0.

During server rendering and hydration, `theme` and `colorScheme` equal their defaults and `"system"` resolves to light. The saved values arrive right after hydration. For styles, prefer the `--cs-*` tokens: they follow the theme and the color scheme without a render.
