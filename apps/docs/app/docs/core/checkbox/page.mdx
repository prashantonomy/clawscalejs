# Checkbox

A **Checkbox** turns one option on or off. A third, indeterminate state shows a partial selection.

## Usage

```tsx
import { Checkbox } from "@clawscale/react";
```

```tsx
<Checkbox checked={retry} label="Retry failed tasks" onChange={(event) => setRetry(event.currentTarget.checked)} />
```

## Examples

### Basic

`defaultChecked` sets the initial state of an uncontrolled checkbox. Pass `checked` and `onChange` to control it.

### Indeterminate

`indeterminate` shows a dash instead of a check. Use it on a select-all checkbox when only some items are selected.

### Inline

`inline` places checkboxes on one line.

<Example name="core/checkbox/inline">
  <CheckboxInline />

### Disabled

`disabled` blocks changes in every state.

### Align right

`alignIndicator="end"` moves the box after the label. Use it in settings lists with a fixed width.
