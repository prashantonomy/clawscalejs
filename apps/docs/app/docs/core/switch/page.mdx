# Switch

A **Switch** turns a setting on or off, and the change applies at once. Use a [Checkbox](/docs/core/checkbox/) for choices that a form submits later.

## Usage

```tsx
import { Switch } from "@clawscale/react";
```

```tsx
<Switch checked={paused} label="Pause ingestion" onChange={(event) => setPaused(event.currentTarget.checked)} />
```

## Examples

### Basic

Pass `checked` and `onChange` to control the switch, or `defaultChecked` to leave it uncontrolled. The whole label is clickable.

<Example name="core/switch/basic">

</Example>

### Inner labels

`innerLabel` shows text inside the track while the switch is off. `innerLabelChecked` replaces it while the switch is on.

### Alignment

`alignIndicator="end"` moves the switch after the label. Use it in settings lists with a fixed width.
