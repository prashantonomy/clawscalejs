# Non-ideal state

A **NonIdealState** explains why content is missing and what to do next. Use it for empty results, errors and views with no data yet.

## Usage

```tsx
import { NonIdealState } from "@clawscale/react";
```

The component renders `icon`, `title`, `description`, `action` and `children`, in that order. For a loading state, pass a [Spinner](/docs/core/spinner/) as `icon`.
