# Divider

A **Divider** draws a thin line between blocks of content. It turns vertical in a flex row, with no extra styles.

## Usage

```tsx
import { Divider } from "@clawscale/react";
```

```tsx
<Divider />
```

## Examples

### Basic

In block layout, a divider spans the width of its container. `compact` removes its margin.

<Example name="core/divider/basic">
  <DividerBasic />
</Example>

### Vertical

In a flex row, such as a toolbar or [Button group](/docs/core/button-group/), a divider becomes a vertical line between items.
