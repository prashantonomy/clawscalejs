# Getting started

Install one package, load one stylesheet, wrap your app once.

## Install

```bash
npm install @clawscale/react
```

Clawscale supports React 18 and 19. It installs Blueprint for you, pinned to a tested version.

## Add the styles

Load the stylesheet once, at the root of your app.

```tsx
import "@clawscale/react/styles.css";
import "@clawscale/react/fonts.css";
```

`styles.css` holds normalize.css, Blueprint's CSS and the Clawscale layer. `fonts.css` is optional: it loads Inter, JetBrains Mono and Oxanium, the typefaces Clawscale is tuned for. For the futuristic look, also load `@clawscale/react/themes/futuristic.css`. See [Themes](/docs/themes/).

## Wrap your app

```tsx
import { ClawscaleProvider } from "@clawscale/react";

export function App() {
  return <ClawscaleProvider>{/* your app */}</ClawscaleProvider>;
}
```

`ClawscaleProvider` sets up overlays, hotkeys and portals, and manages the theme and the light, dark and system color schemes. See [Clawscale provider](/docs/core/clawscale-provider/).

## Entry points

| Import | Contents |
| --- | --- |
| `@clawscale/react` | Core components, hooks and Clawscale patterns |
| `@clawscale/react/select` | Select, Suggest, MultiSelect, Omnibar, QueryList |
| `@clawscale/react/datetime` | Date and time pickers and inputs |
| `@clawscale/react/table` | The spreadsheet-like Table |
| `@clawscale/react/icons` | Icon names, icon components and the icon loader |
| `@clawscale/react/common` | Constants that are safe in React Server Components |
| `@clawscale/react/sync-icons` | Synchronous icon loading for server rendering |
| `@clawscale/tokens` | Design tokens as CSS variables, JSON and TypeScript |

## Browser support

Clawscale targets the last two versions of Chrome, Edge, Firefox and Safari. It needs CSS cascade layers and `color-mix()`. The futuristic theme also uses `@scope`, `light-dark()` and `corner-shape`, and degrades where they are missing.
