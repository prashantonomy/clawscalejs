# Suggest

**Suggest** picks one item from a list by typing. It renders a text input instead of a button, so it suits users who know what they want.

## Usage

```tsx
import { Suggest } from "@clawscale/react/select";
```

Suggest takes the shared [item props](/docs/select/#item-model), plus `inputValueRenderer`.

## Examples

### Basic

`inputValueRenderer` turns the selected item into the input text. It is required. Pass `selectedItem` to control the choice, or leave it out to let Suggest keep it.

</Example>

### Close on select

`closeOnSelect={false}` keeps the list open after a pick, so users can try several items in a row.

### Reset on close

`resetOnClose` clears the query and the active item when the list closes. Type part of a name, then click away: the input empties instead of keeping the partial query.
