# Charts

Clawscale ships chart tokens, not a chart library. Use them with the chart library you already have, or draw small charts in SVG.

## Usage

In SVG and CSS, read the tokens as CSS variables. They follow the theme and the color scheme.

```tsx
<path d={line} fill="none" stroke="var(--cs-chart-1)" strokeWidth={2} />
```

Libraries that need color values import them from `@clawscale/tokens`.

```tsx
import { chartPalettes } from "@clawscale/tokens";
```

## Categorical palette

Eight slots, `--cs-chart-1` to `--cs-chart-8`, tell series apart. Each theme and color scheme has its own values, tuned for its surface.

<Example name="patterns/charts/palette" align="start">
  <ChartsPalette />
</Example>

- Assign slots in order: the first series gets slot 1, the second slot 2. The order keeps neighboring colors distinct for color-blind readers.
- Never skip, reorder or cycle slots. A ninth series folds into Other, or the chart splits into small multiples.
- Color follows the series, not its rank. When a filter hides a series, the others keep their colors.
- One series uses slot 1 and needs no legend. The title names it.
- Two or more series need a legend. Up to four also get direct labels.
- In the default theme's light color scheme, slots 3, 4 and 5 fall below 3:1 contrast on the surface. In the futuristic theme's, slot 6 does. Label those series directly or offer a table.

## Status colors

`--cs-chart-good`, `--cs-chart-warning`, `--cs-chart-serious` and `--cs-chart-critical` show state, never series identity. They are the same in every theme and color scheme. Warning and serious are low contrast on light surfaces by design, so always show a status color with an icon and a label.

## Grid and axis

`--cs-chart-grid` draws hairline gridlines and `--cs-chart-axis` draws the baseline. Both stay quiet so the data leads. Axis labels and values use text tokens such as `--cs-color-text-muted`, never a series color.

## Sequential ramp

`--cs-chart-seq-100` to `--cs-chart-seq-700` step one hue from light to dark: blue in the default theme, cyan in the futuristic theme. Use it for magnitude, such as heatmap cells. In the light color scheme, map values near zero to 100. In the dark color scheme, reverse the ramp so low values stay close to the surface.

## Rules for hand-built charts

- One y axis. Two measures with different scales get two charts.
- Lines are 2px. Bars sit 2px apart, with 4px rounded corners at the data end and a square base.
- Gridlines are solid hairlines in `--cs-chart-grid`.
- Labels and values use text colors. The colored mark next to a label carries identity.
- Numbers use tabular figures: add `ClawscaleClasses.NUMERIC` to the `svg`.
- Every mark has a native `<title>`, which the browser shows on hover.
- Every chart has a visually hidden data table or an `aria-label` summary for screen readers.

## Chart libraries

SVG libraries such as Recharts accept CSS variables, so `stroke="var(--cs-chart-1)"` works there too. Canvas renderers such as ECharts, and libraries that compute colors such as Vega, need color values. Read the theme and color scheme with [useTheme](/docs/core/use-theme/) and pass the matching entry of `chartPalettes`.

```tsx
"use client";

import { useTheme } from "@clawscale/react";
import { chartPalettes } from "@clawscale/tokens";

export function useChartPalette() {
  const { theme, resolvedColorScheme } = useTheme();
  return chartPalettes[theme === "futuristic" ? "futuristic" : "default"][resolvedColorScheme];
}
```

Index the palette by each series' position in the full list, not in the filtered one, so colors never shift.

```tsx
// Recharts
const palette = useChartPalette();

<LineChart data={throughput}>
  {regions.map((region, index) => (
    <Line key={region} dataKey={region} stroke={palette[index]} strokeWidth={2} dot={false} />
  ))}
</LineChart>;
```

```tsx
// ECharts
const palette = useChartPalette();

chart.setOption({ color: [...palette], series });
```

```tsx
// Vega-Lite
const palette = useChartPalette();

const spec = { ...throughputSpec, config: { range: { category: [...palette] } } };
```

Grid, axis and status colors for each theme are in `light.chart` and `dark.chart`. The sequential ramp is `sequentialBlue`. All three come from `@clawscale/tokens`.
